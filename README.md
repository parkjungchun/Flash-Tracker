# ⚡ 점멸 쿨타임 트래커 (Flash Cooldown Tracker)

리그 오브 레전드 인게임에서 상대 챔피언의 점멸 쿨타임을 빠르게 계산하고 팀원과 공유하기 위한 도구입니다.

---

## 기능

- **5개 라인 개별 관리** — 탑 / 정글 / 미드 / 원딜 / 서폿 각각 독립적으로 추적
- **자동 쿨타임 계산** — 사용 시각을 입력하면 완료 시각을 자동으로 계산
- **룬/아이템 쿨타임 반영** — 장화(저항의 장화) / 통찰(코즈믹 인사이트) 선택 시 쿨타임 자동 감소
- **전체 복사** — 모든 라인의 점멸 완료 시각을 한 번에 클립보드로 복사
- **초기화** — 한 번에 모든 상태 리셋

---

## 쿨타임 기준

| 조건 | 쿨타임 |
|------|--------|
| 기본 | 5:00 (300초) |
| 장화 착용 | 4:27 (267초) |
| 통찰 룬 | 4:14 (254초) |
| 장화 + 통찰 | 3:50 (230초) |

---

## 사용 방법

1. **룬/아이템 선택** (선택사항)  
   해당 라인에 장화 또는 통찰 룬이 있으면 버튼을 클릭해 활성화합니다.  
   → 쿨타임이 자동으로 조정됩니다.

2. **점멸 사용 시각 입력**  
   분(MM)과 초(SS) 입력란에 게임 시간을 입력합니다.  
   → Enter 키로 분에서 초로, 초에서 입력 확정으로 이동할 수 있습니다.

3. **입력 버튼 클릭**  
   완료 시각이 오른쪽에 표시됩니다. (예: `06:47 완료`)

4. **전체 복사**  
   입력된 라인들의 결과를 `top 06:47 mid 08:20` 형식으로 복사합니다.  
   → 팀 채팅에 그대로 붙여넣기 하세요.

5. **취소 / 초기화**  
   라인별 취소 또는 전체 초기화 버튼으로 상태를 되돌립니다.

---

## 복사 형식 예시

```
top 06:47 jug 09:15 mid 08:20
```

| 약어 | 라인 |
|------|------|
| `top` | 탑 |
| `jug` | 정글 |
| `mid` | 미드 |
| `ad`  | 원딜 |
| `sup` | 서폿 |
