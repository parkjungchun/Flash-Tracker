# ⚡ Flash Tracker

리그 오브 레전드 점멸 쿨타임 트래커

---

## 사용법

1. 적 챔피언이 점멸을 사용한 **게임 내 시간**을 입력 (시:분:초)
2. **입력** 버튼 클릭 (또는 초 입력 후 Enter)
3. 해당 라인 카드에 **남은 쿨타임이 카운트다운**으로 표시됨
4. 쿨타임이 완료되면 **자동 초기화**
5. 하단 미리보기 텍스트는 `사용시간 + CD = 완료 게임시간` 기준으로 고정 표시

---

## 쿨타임 감소 옵션

쿨타임은 `300 × 100 / (100 + 주문가속 합계)` 공식으로 계산됩니다.

| 옵션 | 주문가속 | 단독 CD | 우통 조합 CD |
|------|---------|---------|------------|
| 기본 | — | 300초 | — |
| 장화 | +10 | 272초 | 234초 |
| 업글장화 *(미드 전용)* | +20 | 250초 | 217초 |
| 우통 | +18 | 254초 | — |

- **장화 / 업글장화**는 상호 배타 (하나만 선택 가능)
- **업글장화** 버튼은 미드 라인에만 표시됨

---

## 라인별 단축 표기 (미리보기)

| 라인 | 표기 |
|------|------|
| 탑 | `top` |
| 정글 | `jug` |
| 미드 | `mid` |
| 원딜 | `ad` |
| 서폿 | `sup` |

---

## 기타

- **취소** 버튼: 해당 라인 개별 초기화
- **초기화** 버튼: 전체 라인 초기화
- 미리보기 텍스트는 드래그하여 채팅창에 바로 붙여넣기 가능
